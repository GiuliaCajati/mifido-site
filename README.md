# MiFido Landing Page

Minimal landing page for MiFido (mifido.ai) - a gentle wellness app for breathwork, journaling, and daily practices that build self-trust.

## Features

- Minimal, calm, premium wellness design (Free People Fit / Alo aesthetic)
- Fully responsive (desktop and mobile)
- Single page, no routing
- App Store download link integration

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- React 19
- Vite
- CSS only (no CSS frameworks)
